# Sony RAW Panel — portable 0.8.0

Автор: **Alexey Storozhilov** · [GitHub](https://github.com/llWHiTE/sony-raw-panel)

**Sony RAW Panel создана для максимально корректной проявки RAW-снимков с камер Sony через родной Sony Imaging Edge Edit и удобной дальнейшей ретуши в Photoshop.** Панель не имитирует Sony-проявку профилем Camera Raw: обработку `.ARW` выполняет установленный оригинальный Sony Edit, а Photoshop получает полноразмерный 16-битный результат. Отдельная ветка Adobe открывает настоящий встроенный RAW-смарт-объект Camera Raw; оба варианта можно сравнить перед выбором.

Это цель рабочего процесса, а не обещание единственного «правильного цвета»: итог зависит от профиля камеры, настроек проявки, версии движка и цветоуправления. Краткое описание проекта — в [README.md](README.md), пошаговые сценарии — в [PANEL.md](PANEL.md).

**[Скачать последнюю версию](https://github.com/llWHiTE/sony-raw-panel/releases/latest)** · [История версий](CHANGELOG.md) · [Подробная инструкция](PANEL.md)

## Что нового в 0.8.0

- **Независимые профили в готовом сравнении:** смена Adobe обновляет только Adobe-слой, смена Sony — только Sony. Показанный проявщик и CUBE сохраняются; полноразмерный результат использует последние подтверждённые настройки.
- **Кэш рассчитанных Sony/Adobe-превью и полного Sony**, отдельно от RAW-проектов. Точные ключи учитывают RAW, полный рецепт/XMP, версии движка и профилей, размеры и цвет. Начальный лимит — 5 ГБ; повторный вариант не требует нового экспорта при попадании в кэш.
- **Предварительный полный Sony** и **превью следующего кадра** — отдельные включаемые настройки. По умолчанию затратная фоновая проявка выключена, а проверенная копия одного следующего RAW готовится автоматически.
- **Очередь нескольких RAW:** добавление, multi-drop и передача из Проводника, стрелки предыдущего/следующего кадра, отдельные настройки кадров, перестановка и удаление ожидающих записей. Переход к следующему кадру явный, не автоматический импорт всех файлов.
- **Компактная панель**, контекстная видимость только рядом с Photoshop/Sony, настраиваемые глобальные горячие клавиши и действия для связанного RAW/проекта.
- **«Отправить → Sony RAW Panel»** подключается отдельной кнопкой меню. Повторный EXE передаёт файлы уже работающей панели, не теряя аргументы и не заменяя незавершённую коррекцию.
- Адаптивные ожидания вместо фиксированных пауз открытия/навигации Sony, меньше повторных COM/JSX-проверок, приоритет ручных задач над фоновой подготовкой и сканированием.
- Собственная многоразмерная иконка EXE и окон панели. Это оригинальный значок проекта, не логотип Sony/Adobe.

Подробные инструкции новых режимов — ниже и в [PANEL.md](PANEL.md). Холодная RAW-проявка остаётся затратной: кэш ускоряет повторное использование, а не меняет демозаик Sony. Замеры без кэша и с попаданием разделены в [BENCHMARK.md](BENCHMARK.md).

## Требования и запуск

- Windows 10/11 x64.
- Установленный **Adobe Photoshop с COM/JSX и Camera Raw**.
- Для Sony и сравнения — **Sony Imaging Edge Edit**, не только Desktop launcher.
- Python, плагины Adobe, режим разработчика и права администратора **не нужны**.

Скачайте `SonyRAWPanel-0.8.0-portable.zip` из [релиза 0.8.0](https://github.com/llWHiTE/sony-raw-panel/releases/tag/v0.8.0), распакуйте и запустите `SonyRAWPanel.exe` из обычной локальной папки с правом записи. Альтернатива — скачать отдельный `SonyRAWPanel.exe` и `SHA256SUMS.txt` из того же релиза. Не используйте Program Files или защищённую сетевую папку.

При первом запуске runtime распаковывается в соседнюю папку `data/runtime-…`. Это распаковка, а не установка. В `data` также находятся настройки, RAW-проекты, рецепты и кэш. Для переноса текущих проектов сохраняйте всю папку вместе с EXE.

EXE не подписан сертификатом издателя. Windows SmartScreen может показать предупреждение. Проверяйте SHA-256 по файлу релиза; панель не отключает защиту Windows.

### Обновление

1. Завершите текущую операцию и закройте старую панель.
2. Замените EXE новым **в прежней папке**.
3. **Не удаляйте `data`**: там находятся проекты, Sony-рецепты и настройки.

Старые неработающие CUBE-слои версии 0.5.1 автоматически не переписываются. В существующем PSD повторно загрузите `.cube` в свойствах Color Lookup (**3D LUT File → Load 3D LUT**), сохраняя ретушь; либо создайте новый результат новой версией.

## Поиск приложений

Панель ищет Sony Edit и Photoshop по регистрации приложений и запущенным процессам. Результат сохраняется в `data/settings.json`.

Если приложение не найдено, запустите его самостоятельно и выберите **⋯ → Программы и пути → Найти заново**. Там же можно указать `Edit.exe` / `Photoshop.exe` вручную. Неверные пути другого компьютера игнорируются. Найденный EXE сам по себе не добавляет COM/JSX в сборку Photoshop без этой поддержки.

## Быстрый старт

1. Выберите **Проявка при открытии: Sony / Adobe**.
2. Нажмите **Добавить RAW…** или перетащите один/несколько `.ARW` на панель. Несколько файлов образуют очередь; во время коррекции новые файлы только добавляются в ожидание.
3. Сразу появятся модель камеры и списки профилей. Кадр ещё **не открывается и не проявляется**. В фоне подготавливается проверенная рабочая копия.
4. Выберите **Профиль Adobe** и **Профиль Sony**. Первый выбор для каждой камеры — Camera Standard; последующие предпочтения сохраняются отдельно по модели.
5. При желании выберите LUT/XMP; по умолчанию **Без LUT**.
6. Нажмите **Открыть в Photoshop** или **Сравнить Sony / Adobe…**.

Добавление и проявка теперь раздельные действия: первый щелчок по «Открыть»/«Сравнить» без добавленного RAW предлагает выбрать файл, после чего даёт возможность настроить профили. Второе действие запускается явно.

### Профили Adobe

Список формируется из **установленных Camera Raw профилей данной модели**. Среди поддерживаемых вариантов:

- Camera Standard / Camera ST;
- Adobe Color;
- Adobe Standard;
- Adobe Portrait;
- Camera Portrait / Camera PT;
- Camera Vivid / Camera VV;
- остальные установленные camera-matching DCP и Adobe Raw профили этой модели.

PT и VV не подменяются Adobe Portrait/Color: это разные варианты. Если профиль отсутствует в установленном Camera Raw, панель его не предлагает и не заменяет другим молча. Обновите Camera Raw для новых камер.

### Профили Sony и разные камеры

Sony Creative **Style** и Creative **Look** — разные наборы. В панели используются реальные идентификаторы и названия списка Imaging Edge; список запоминается по модели при штатной проявке. A7R III и A7R V имеют начальные каталоги, проверенные в Sony Edit. Для A7R V доступны ST/PT/NT/VV/VV2/FL/IN/SH/BW/SE; у A7R III — Standard/Portrait/Vivid/Neutral и другие Creative Style.

**Новая, ещё не встречавшаяся модель:** без открытия RAW Sony не предоставляет полный отдельный каталог творческих стилей. Поэтому до первой необходимой Sony-проявки панель показывает только Camera Standard. При этой проявке считывается настоящий список Creative Style/Look и сохраняется для следующих добавлений RAW данной модели. **Лишнего открытия ради списка не выполняется.** Перед применением выбранный вариант повторно проверяется в реальном Sony — устаревший кэш не приводит к тихой подмене профиля.

### Сравнение

Выберите масштаб **100%, 75%, 50%** или сохранённый собственный целый процент 1–100 от ширины и высоты конкретного ARW. Одна кнопка создаёт сравнение, затем переключает Sony/Adobe в одном документе. Переключение готовых слоёв не запускает новую проявку.

**LUT в готовом сравнении:** выберите другой `.cube` или **Без LUT** в том же списке — эффект применяется сразу к обеим веткам, без создания нового сравнения. Документ, размер, ориентация и показанный проявщик сохраняются; лишние слои LUT не накапливаются. Длительность смены видна внизу панели.

Выбор/отключение `.xmp` требует обновления **только Adobe**; Sony не экспортируется повторно. При переходе XMP → CUBE сначала восстанавливается Adobe без прежнего пресета, затем добавляется общий CUBE. Если сравнение восстановлено из версии до 0.7.0, CUBE можно менять сразу, а для XMP понадобится создать новое сравнение с базовым частным XMP.

Смена LUT не перезаписывает вручную изменённое сравнение. При ошибке предыдущий эффект/выбор сохраняется; исправьте причину и повторите команду либо завершите сравнение. Не редактируйте служебное превью перед выбором рабочего документа.

**Использовать Sony / Adobe RAW · полный размер** создаёт рабочий документ из показанного варианта, с **теми же зафиксированными профилями и LUT**, но из полного RAW, не увеличивая превью. Проценты учитывают EXIF-ориентацию; растягивание пропорций запрещено.

Не ретушируйте служебное сравнение — сначала выберите рабочий вариант. Неизменённое сравнение закрывается после выбора; изменённые/неоднозначные превью сохраняются вместе с файлами.

### Редактирование

**Sony:**

- С галочкой **Сначала настроить в Sony** рабочая копия открывается с выбранным стилем без начального TIFF/документа Photoshop. Настройте RAW и нажмите **Применить в Photoshop**.
- Для дальнейшей коррекции выберите Sony-документ и нажмите **Изменить проявку в Sony**. Рецепт нужной версии восстанавливается. Чтобы явно изменить стиль из панели, выберите новый профиль перед этой командой; без нового выбора используется сохранённый стиль, а не глобальный профиль другого снимка.
- Ретушируйте на отдельных слоях над Sony-смарт-объектом. **Применить** обновляет его содержимое, сохраняя слои ретуши и LUT.
- Если рецепт не изменился, TIFF не создаётся. Профиль является частью рецепта, поэтому его реальное изменение вызывает обновление. Ручные изменения Sony не сбрасываются глобальными списками при Apply.

**Adobe:** выбранный профиль/Look входит в RAW-настройки встроенного смарт-объекта. Двойной щелчок по нему открывает Camera Raw для дальнейшего изменения профиля, баланса белого и остальных RAW-параметров. Общие списки панели не переписывают уже открытые Adobe-документы.

## LUT и XMP

По умолчанию — **Без LUT**.

- **CUBE** — отдельный отключаемый слой Color Lookup над Sony/Adobe, общий слой в сравнении. Внутри PSD сохраняются таблица и бинарный профиль; удаление библиотечной копии не отключает уже встроенный эффект.
- **XMP · Adobe** — Camera Raw пресет, работает только с частной Adobe-копией. В сравнении Sony XMP не использует. Прямое Sony-открытие с XMP отклоняется с пояснением.
- **Приоритет профиля:** выбранный в панели Adobe-профиль имеет приоритет над CameraProfile и Look пресета XMP. Экспозиция, цветовые настройки и пользовательские кривые пресета сохраняются, конкурирующая Look-таблица заменяется выбранным профилем. Поэтому Sony To Leica с явно выбранным Camera Standard может выглядеть иначе, чем исходный пресет с собственным Adobe Standard/Look.

**…** рядом со списком позволяет добавить `.cube` / `.xmp` и удалить любые начальные записи. Удаляется только библиотечная копия, не оригинал или слой в PSD. Удалённые начальные файлы не возвращаются после перезапуска. Включены восемь предоставленных LUT и Sony To Leica.xmp с разрешения на распространение; условия отдельные от MIT.

## Профили в готовом сравнении

Оба списка профилей доступны после создания сравнения. Выбор применяется сразу к своей ветке; повторный выбор того же профиля ничего не проявляет. Adobe-профиль меняет только Adobe-копию/слой и обновляет базовый частный XMP; текущий XMP-пресет применяется заново с приоритетом выбранного профиля. Sony-профиль меняет только Sony-рецепт/превью. CUBE и вторая ветка не заменяются.

Панель проверяет историю/слои до подготовки и перед заменой. При ручной правке сравнения операция отказывается от замены; при неудаче выбор возвращается к последнему подтверждённому профилю. Не переключайте кадры и не меняйте параметры Sony во время команды. Размер превью по-прежнему меняется созданием нового сравнения.

## Очередь RAW и подготовка следующего кадра

Добавьте несколько файлов одним выбором, перетаскиванием или через «Отправить». Стрелки **‹ / ›** и **Кадр N из M · очередь** выбирают кадр; **⋯ → Очередь RAW…** открывает список, перестановку и удаление записи. Удаление из очереди не удаляет оригинал или рабочий проект. Сначала завершите сравнение/коррекцию перед переходом. Очередь и настройки кадров сохраняются между запусками; прерванная работа не повторяется автоматически как импорт.

В фоне готовится проверенная копия одного следующего кадра. Повторный выбор использует уже подготовленный проект. Отдельно можно включить:

- **⋯ → Готовить полный Sony заранее**: после готовности сравнения рассчитать полный Sony TIFF по его зафиксированному рецепту. При выборе Sony готовый job проходит обычные проверки встраивания/ack. Если работа ещё идёт, команда ожидает её, не запускает второй экспорт. Изменение Sony-профиля инвалидирует старый полный результат; Adobe-профиль и CUBE не требуют нового Sony TIFF.
- **⋯ → Готовить превью следующего кадра**: после подготовки копии следующего кадра рассчитать его Sony-превью в кэш. При лимите кэша `0` готовится только RAW-копия, без бесполезного экспорта превью. Adobe во время ретуши спекулятивно не открывается. При выборе кадра использована зафиксированная конфигурация/кэш, а не профиль другой камеры.

Обе затратные настройки **выключены по умолчанию**. Все команды к приложениям последовательны. Ручные задания выше ожидающих фоновых, но уже выполняющийся экспорт нельзя безопасно прервать. В этот момент интерфейс сообщает, что ручная команда будет следующей.

Фоновая Sony-проявка откладывается, если Sony закрыт/свёрнут, активна другая программа, открыт диалог, идёт ручная коррекция или обнаружен чужой/изменённый RAW. Она не запускает Sony спекулятивно и не сбрасывает ручные параметры. Через UI-автоматизацию нельзя обещать полностью невидимый экспорт: короткие служебные диалоги возможны. Используйте фоновые режимы, только если это подходит вашему процессу.

## Кэш рассчитанных изображений

**⋯ → Кэш готовых изображений…** задаёт лимит (начально **5 ГБ**, `0` — выключить) и удаляет незакреплённые изображения **без Photoshop Purge**. При переполнении удаляются старые derived TIFF, а не RAW/рецепты. Занятые entries могут временно превышать лимит; есть проверка свободного места. Незавершённые импорты не считаются одноразовыми файлами.

Ключ учитывает SHA-256 RAW, полный Sony-рецепт или эффективный Adobe XMP/Look, установленные файлы/версию движка и профилей, геометрию, 16-битность и sRGB. CUBE хранится отдельно. Изменённые зависимости дают промах, повреждённая/недописанная запись не используется. Первая проверка полная, повторная использует идентичность и версию файла, включая Windows ChangeTime и NTFS USN. Если файловая система не предоставляет USN, содержимое проверяется повторным хешем вместо доверия одним временным меткам. Полный Adobe всегда открывается как встроенный RAW, не как растровая копия кэша.

## Окно, горячие клавиши и Проводник

- **⋯ → Компактная панель** оставляет основные действия/текущий кадр. Возврат тем же пунктом восстанавливает полный интерфейс.
- **⋯ → Показывать только в Photoshop / Sony** автоматически убирает панель поверх других приложений и возвращает при переходе в Photoshop/Sony. Собственные диалоги панели считаются её частью; ручное скрытие не отменяется автоматически. Настройка изначально выключена. Вернуть скрытую панель можно повторным запуском того же EXE или включённой глобальной клавишей.
- **⋯ → Глобальные горячие клавиши…** включает/настраивает: `Ctrl+Alt+Shift+S` — открыть выбранный Sony-объект для коррекции; `Ctrl+Alt+Shift+Enter` — применить известную текущую коррекцию/повторить импорт; `Ctrl+Alt+Shift+P` — показать/скрыть панель. Изначально выключены; конфликты показываются, чужие сочетания не перехватываются. Edit/Apply не действуют из посторонней программы и не выбирают случайный объект. При выходе регистрация снимается. Локальные Ctrl+O/Ctrl+Enter сохранены.
- **⋯ → Подключить «Отправить» Проводника** создаёт только пользовательский ярлык на текущий portable EXE. После этого выделите ARW в Проводнике → **Отправить → Sony RAW Panel** (в Windows 11 может понадобиться **Показать дополнительные параметры**). Передаются только пути; нет автоматической проявки/импорта. **Удалить «Отправить»** удаляет только собственный ярлык. Одноимённый ярлык другой portable-папки не перезаписывается: удалите/переименуйте его явно. После переноса EXE проверьте ярлык. Реестр/ассоциации ARW/автозагрузка не меняются; source-режим требует запуска portable EXE для установки ярлыка.
- Правая кнопка на имени кадра / **⋯ → Текущий кадр…**: показать оригинал, скопировать путь, открыть папку Sony-проекта и посмотреть связь RAW/project/revision/recipe. Это навигация, не удаление файлов. Для Photoshop-цели связь проверяется по актуальному выбранному объекту.

## Скорость и фоновая подготовка

- Добавление читает небольшие TIFF/Exif-метаданные, не декодирует RAW и не открывает изображение в приложениях.
- Каталог Adobe кэшируется по модели и переиспользуется; изменение установленных файлов профилей инвалидирует кэш.
- Sony-списки берутся из проверенного/наблюдённого каталога по модели, фактическая проверка выполняется при необходимой проявке.
- В фоне создаётся независимая проверенная RAW-копия для выбранного проявщика. Если сразу нажать открыть/сравнить, операция дождётся уже начатой подготовки, не создавая вторую копию для Sony.
- Результат не проявляется заранее с ещё не выбранным профилем. Изменение профиля не выбрасывает готовую RAW-копию.
- Повторный выбор неизменённых LUT/ICC использует кэш до 64 записей в памяти процесса. Изменение версии файла инвалидирует запись; после перезапуска проверка выполняется заново. Отсутствующий/повреждённый ICC пересоздаётся. Первые проверки хешей и геометрии не отключены.
- Сравнение и переключение Sony/Adobe больше не делают отдельный лишний `inspect`-запрос Photoshop. Проверка истории усилена идентификатором текущего состояния, а не только количеством записей.
- После применения Sony-профиля используется уже сохранённый и проверенный XML-рецепт, без второго одинакового диалога сохранения.
- В собственной панели нет дополнительного GPU-движка: расчёты выполняют Sony/Camera Raw, использующие своё аппаратное ускорение. Панель не меняет глобальные GPU-настройки приложений и не обещает ускорение, которого их API не предоставляет.

На проверенном компьютере каталог A7R III при первом чтении занимал **около 85 мс**, фоновая проверенная копия — **около 0,10 с**. Это наблюдения локального теста на быстром диске, не гарантия для другого диска/RAW. Фоновая подготовка переносит небольшую часть ожидания до нажатия кнопки, но не устраняет вычисления Sony. Измерения масштабов предпросмотра — в [BENCHMARK.md](BENCHMARK.md).

## Данные, ошибки и очистка

- Оригинальные ARW/XMP не перезаписываются. Создаются независимые проверенные копии.
- **`data/projects` — не одноразовый кэш:** рабочие Sony ARW и версии рецептов нужны для дальнейшего редактирования. PSD с Sony-растром не заменяет эту папку.
- `data/adobe-projects` хранит прямые Adobe-копии. Подтверждённый Adobe RAW-смарт-объект встроен в PSD, не связан с внешним ARW.
- TIFF удаляется только после подтверждённого встраивания. После ошибки можно **Повторить импорт в Photoshop** без повторного Sony-экспорта.
- **Отменить проявку** освобождает панель после ошибки/незавершённой операции без изменения документов и оригиналов. Готовый результат и состояние сохраняются в данных. Кнопка не прерывает уже работающий экспорт.
- Продолжительность открытия, сравнения и применения остаётся видимой после завершения.

**Очистить кэш** одной кнопкой удаляет подтверждённые временные TIFF, закрывает только идентифицированные неизменённые служебные сравнения Photoshop и соответствующие неизменённые Sony-вкладки, затем выполняет штатный Photoshop `ALLCACHES`.

**Внимание: очищаются история отмены и буфер обмена ВСЕХ документов Photoshop.** Перед очисткой есть предупреждение с **Больше не показывать**; вернуть предупреждение можно через **⋯ → Предупреждать при очистке кэша**. Рабочие документы остаются открыты; RAW, рецепты, неподтверждённые результаты и изменённые/неоднозначные превью сохраняются. Camera Raw disk cache не удаляется; обнуление всей RAM не обещается.

## Ограничения

- Sony-движок не переносится внутрь Camera Raw. Photoshop получает 16-битный sRGB-результат Sony, а повторная RAW-коррекция выполняется Imaging Edge.
- Не переключайте снимки Sony во время экспорта; неизвестные диалоги автоматически не подтверждаются.
- Смена геометрии при обновлении ретушированного проекта блокируется, чтобы не сместить ретушь.
- Проверено на A7R III / A7R V, Imaging Edge Edit 4.0.00.10311 и Photoshop 27.12.0. Другие камеры/версии требуют проверки совместимости.
- Кэш профилей не обещает полную поддержку неизвестной камеры: первый реальный вызов проверяет доступность стиля.
- Панель плавающая, не докируемый Photoshop-плагин.
- Фоновая RAW-копия остаётся в проектных данных даже если вы передумали открывать фото: это не повод автоматически удалять рабочие RAW.

## Диагностика и сборка

Самопроверка EXE без открытия фото:

```bash
SonyRAWPanel.exe --self-check
```

Отчёт — `data/self-check.json`. Ошибки — `data/panel-logs`. Не публикуйте эти файлы вместе с локальными путями и проектами.

Сборка на Windows x64 с официальным CPython 3.14 и штатным .NET Framework C# compiler:

```bash
python build_portable.py --python-home C:/Path/To/Python314 --output dist
```

Запуск исходников:

```bash
python sony_panel.py
```

Модульные тесты (Sony/Photoshop не запускаются; для JSX-проверок нужен Node.js):

```bash
python -m unittest discover
```

Сквозная проверка с отдельным тестовым RAW-проектом (запускает приложения, оригинал не меняет):

```bash
SonyRAWPanel.exe --verify-raw C:/Photos/example.ARW
```

Результат — `data/workflow-verification.json`. Сборщик включает только перечисленные исходники, документы, разрешённые творческие материалы и runtime. **Фотографии, проекты, кэш, локальные настройки и файлы профилей Adobe/Sony в релиз не включаются.**
