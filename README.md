# Sony RAW Panel — portable 0.5.0

Автор: **Alexey Storozhilov**

GitHub: https://github.com/llWHiTE/sony-raw-panel

Портативная сборка предоставляется файлами `SonyRAWPanel.exe` и `SHA256SUMS.txt`. Исходники: [GitHub](https://github.com/llWHiTE/sony-raw-panel). Страница выпусков: [Releases](https://github.com/llWHiTE/sony-raw-panel/releases). Репозиторий приватный: для доступа нужен вход в аккаунт владельца или приглашённого участника. Подробная инструкция по кнопкам — [PANEL.md](PANEL.md).

## Запуск

Скопируйте `SonyRAWPanel.exe` в обычную папку с правом записи и запустите. Установка Python, плагины Adobe, режим разработчика и права администратора не нужны. Поддерживается Windows 10/11 x64; требуются установленный Photoshop с COM/JSX и Sony Imaging Edge **Edit**, а не только Desktop launcher.

При первом запуске EXE распаковывает включённый Python/Tk runtime в соседнюю папку `data/runtime-…`. Это распаковка, не установка. Папка `data` хранит настройки, проекты и кэш. Для переноса сохраните её вместе с EXE. Первый запуск дольше последующих. В сетевой/защищённой папке и Program Files программа может не иметь права записи: используйте обычную локальную папку.

EXE не подписан сертификатом издателя. Windows может показать предупреждение о неизвестном издателе. Сверьте SHA-256 с файлом релиза. Программа не отключает защиту Windows.

## Поиск программ

При запуске панель ищет Sony Edit и Photoshop по реестру и запущенным процессам, сохраняет найденные пути в `data/settings.json`. В меню **⋯ → Программы и пути** показаны найденные приложения.

Если путь не найден, **самостоятельно запустите Sony Edit и Photoshop**, затем нажмите **Найти заново**. Дополнительно можно указать `Edit.exe`/`Photoshop.exe` вручную. После переноса на другой компьютер неверные старые пути игнорируются. Программа не меняет реестр или настройки безопасности. Если COM/JSX недоступен в конкретной сборке Photoshop, один только найденный EXE это ограничение не устраняет.

## Рабочий цикл

- **Проявка при открытии: Sony / Adobe.** Sony использует штатную обработку Imaging Edge. Adobe открывает ARW как встроенный RAW-смарт-объект Camera Raw с профилем Camera ST. Для Adobe запуск Sony не нужен при открытии; при старте панели Sony заранее запускается только если выбран режим Sony.
- **Сначала настроить в Sony.** Для Sony откроется копия ARW без первого TIFF и без преждевременного документа Photoshop. Настройте RAW, затем нажмите «Применить» — будет выполнен один экспорт с выбранными параметрами.
- **Изменить проявку / Применить.** Мост запоминает точные документ, смарт-объект и версию рецепта; верхние слои ретуши сохраняются.
- **Без изменений — без перепроявки.** Перед обновлением Sony сохраняет небольшой XML-рецепт. Если все `DevelopmentParameters` совпадают с рецептом текущего изображения, TIFF не создаётся и Photoshop не обновляет пиксели. Форматирование XML, порядок ключей и эквивалентная запись чисел не считаются изменениями; любые неизвестные/добавленные параметры и ошибки разбора не игнорируются. На такую проверку всё равно требуется время работы диалога Sony.
- **Сравнить.** Выберите 100%, 75%, 50% или сохранённый свой процент (1–100%) от размеров конкретного ARW. Одна кнопка запускает сравнение и затем переключает Sony/Adobe. Кнопка под ней создаёт рабочий документ из показанного варианта в полном разрешении.
- **Итоговое время** остаётся видимым после открытия, подготовки сравнения и применения.
- **Отменить проявку** освобождает панель после ошибки, даже если Photoshop недоступен. Оригиналы, документы и готовые файлы не удаляются; сведения об операции архивируются в `data/cancelled-operations`. Отмена доступна между операциями, не прерывает работающий экспорт.

Двойной щелчок по Adobe RAW-смарт-объекту открывает Camera Raw. Для Sony используйте кнопку моста: встроенное изображение Sony — растр, а возможность RAW-коррекции обеспечивают отдельный исходный ARW и рецепты. Программа не переносит движок Sony внутрь Camera Raw.

Настройки панели (проявщик, чекбокс, разрешение сравнения, «Поверх окон») сохраняются. Одна панель на сеанс Windows; повторный запуск выводит существующее окно.

## Данные и очистка

Оригинальные ARW не записываются: создаются независимые проверенные копии. Папка `projects` содержит рабочие RAW и версии Sony XML и **не является одноразовым кэшем**. Папка `adobe-projects` содержит рабочие копии для прямого Adobe-открытия. PSD сам по себе не хранит Sony RAW/рецепт — сохраняйте папку данных вместе с проектом.

TIFF удаляется только после подтверждения успешного встраивания. Неудачные/неподтверждённые операции остаются для восстановления. **⋯ → Очистить подтверждённый кэш** повторяет безопасную очистку. Нет автоматического удаления исходников, RAW-проектов и истории рецептов.

## Ограничения

- Экспорт Sony — 16-битный sRGB; другие цветовые пространства пока не реализованы.
- Проверено на Sony A7R III и A7R V / Imaging Edge Edit 4.0.00.10311 / Photoshop 27.12.0. Другие версии требуют проверки элементов интерфейса и доступности профиля Camera ST.
- Смена геометрии между проявками может нарушать ретушь и блокируется проверкой размеров/ориентации. Не меняйте кадрирование в текущем ретушированном проекте.
- Во время экспорта не переключайте снимки в Sony. Неизвестные диалоги не подтверждаются автоматически.
- Холодный запуск и вычисления Sony не устраняются упаковкой в EXE.
- Интерфейс плавающий, не докируемый Photoshop-плагин.

## Диагностика и сборка

`SonyRAWPanel.exe --self-check` проверяет runtime, Tk, поиск программ и записывает `data/self-check.json` без открытия изображений.

Сборка на Windows x64 с официальным CPython 3.14 и штатным .NET Framework C# compiler:

```bash
python build_portable.py --python-home C:/Path/To/Python314 --output dist
```

Сторонний сборщик и pip не требуются. Скрипт упаковывает только явно перечисленные исходники приложения и стандартный runtime; фотографии/проекты/журналы не входят. Результат — один EXE, `SHA256SUMS.txt`; промежуточный runtime-payload.zip не требуется распространять.

Для разработки:

```bash
python sony_panel.py
```

Модульные тесты (без запуска Sony/Photoshop):

```bash
python -m unittest test_panel test_bridge test_bridge_v2 test_comparison test_recipe_compare test_runtime_paths test_workflow test_menu_state test_preview_settings test_panel_widgets test_photoshop_host
```

Самопроверка EXE:

```bash
SonyRAWPanel.exe --self-check
```

Сквозная проверка с выбранным ARW (открывает приложения, создаёт отдельный тестовый проект и документ, оригинал не изменяет):

```bash
SonyRAWPanel.exe --verify-raw C:/Photos/example.ARW
```

Отчёт сохраняется локально в `data/workflow-verification.json`; не загружайте его вместе с фотографиями в репозиторий.
